# Example Challenge

Submit one predicted string for each record ID. The evaluator compares your predictions with a reference table and reports positional accuracy, exact matches, edit distance, and normalized edit similarity.

The three tracks share a small synthetic dataset. They demonstrate track selection, private submission history, and an overall leaderboard with equal track weights.

## Try a submission

1. Sign in and create or join a team.
2. Download an example archive from the data page.
3. Select a track and upload the archive.
4. Follow validation and scoring in your submission history.

The sample archive matches the demonstration reference exactly. A perturbed fixture in the repository changes one character in each record and produces a lower score.

## Create your own challenge

Organizers can replace the challenge metadata and Markdown pages, define tracks and deadlines, and supply a trusted evaluator with private reference data. Publish the task, scoring rules, and data access arrangements before participants register.
